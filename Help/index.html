1. Системные требования

  • Операционная система: Microsoft Windows 10 x64 (64-разрядная) или Windows 11 x64 (минимальная поддерживаемая версия — Windows 10x64).
  • Процессор: 64-битный двухъядерный процессор с тактовой частотой 2.0 ГГц или выше.
  • Оперативная память (RAM): минимум 4 ГБ (рекомендуется 8 ГБ и более).
  • Свободное место на диске: не менее 2 ГБ для временных файлов видеомонтажа и кэша аудио.
  • Подключение к сети: широкополосный доступ в интернет для работы с Google Gemini API.
  • Доступность: интерфейс программы полностью оптимизирован для незрячих пользователей и экранных дикторов NVDA и JAWS.

2. Безопасность данных и конфиденциальность

⚠️ ВАЖНОЕ ПРЕДУПРЕЖДЕНИЕ:

1. Ваш персональный API-ключ Google AI Studio является строгим секретом и сохраняется в файле конфигурации Settings.ini в корневой папке программы.

2. Все созданные проекты, черновики тифлокомментариев, а также исходные видеоматериалы (включая личные и семейные видео) хранятся в каталоге Projects/.

Программу с вашим файлом Settings.ini и каталогом Projects нельзя распространять и передавать третьим лицам! Это защитит ваши персональные видеозаписи от утечки, а ваш аккаунт Google API — от несанкционированного расхода квот и средств.

3. Подготовка к работе: Smart DNS, настройка браузеров и Google AI Studio

3.1. Обход географических ограничений (Smart DNS)

Для работы программы необходимо средство обхода региональных ограничений Google. Отличным и простым решением является сервис Smart DNS:

🔗 https://xbox-dns.ru/

Укажите предоставленные на сайте адреса DNS-серверов в свойствах вашего сетевого адаптера Windows (в свойствах протокола IPv4).

3.2. Отключение собственного DNS в браузерах (DNS через HTTPS)

Важная настройка браузера:
Помимо указания адресов DNS в сетевом подключении Windows, для успешного открытия портала aistudio.google.com необходимо отключить использование собственного встроенного DNS-сервера (DNS-over-HTTPS / DoH) в вашем браузере:

Инструкция для Google Chrome:

  1. Откройте меню браузера (кнопка с тремя точками) и перейдите в «Настройки».
  2. Откройте раздел «Конфиденциальность и безопасность» → «Безопасность».
  3. Найдите параметр «Использовать безопасный DNS-сервер».
  4. Выключите тумблер (переведите в неактивное состояние).

Инструкция для Mozilla Firefox:

  1. Откройте меню браузера и зайдите в «Настройки».
  2. Перейдите во вкладку «Приватность и защита» и прокрутите страницу в самый низ до раздела «DNS через HTTPS» (либо откройте «Основные» → «Параметры сети» → «Настроить...»).
  3. Выберите пункт «Отключено» (использовать системный распознаватель по умолчанию).

3.3. Получение API-ключа Google AI Studio

  1. Перейдите по ссылке: 🔗 https://aistudio.google.com
  2. Войдите со своим Google-аккаунтом.
  3. Нажмите «Get API key» и сгенерируйте новый секретный ключ.
  4. Вставьте полученный ключ в программе в окне «Настройки» (Ctrl + P).

3.4. Оплата Google API с помощью зарубежных карт

Для оплаты платных тарифов и повышенных квот Google API требуется банковская карта зарубежного банка. Оформить подходящую карту можно, например, на сервисе:

🔗 https://platipomiru.com/

4. Подробный разбор настроек программы (Ctrl + P)

Окно настроек вызывается через меню Настройки или горячей клавишей Ctrl + P.

Вкладка «Gemini API и модели»:

  • API-ключ Gemini: Поле для ввода вашего персонального ключа Google AI Studio.
  • Кнопка «Загрузить список моделей»: Запрашивает с серверов Google список актуальных моделей.
  • Модель для комментирования: Языковая мультимодальная модель, создающая текст тифлокомментариев (например, gemini-2.5-flash).
  • Модель для Gemini TTS (озвучивание): Выбор модели синтеза речи. Важно: для озвучки тифлокомментариев необходимо выбирать модели, у которых в названии есть пометка "TTS" (например, gemini-3.1-flash-tts-preview). Обычные текстовые модели звук не синтезируют.
  • Голос Gemini TTS: Выбор тембра диктора (Puck, Charon, Kore, Fenrir, Aoede и др.) с кнопкой тестового воспроизведения образца.
  • Продолжительность одной части, передаваемой модели:
    Рекомендованная продолжительность одной части — 10 минут.

    Подробное объяснение:

    • Если установить слишком маленькое значение (1–3 мин): Модель не видит достаточно полной картины сюжета, не успевает понять динамику сцены, взаимоотношения персонажей и контекст происходящего, что ухудшает точность и выразительность описания.
    • Если установить слишком большое значение (20–40 мин и более): Размер текста, выдаваемого моделью за один запрос, строго ограничен лимитом токенов ответа нейросети. Из-за этого лимита модель не может сделать достаточное количество комментариев и пропускает множество свободных пауз в фильме.
    • Значение 10 минут — идеальный баланс: модель успевает глубоко оценить происходящее в сцене и создает максимальное количество подробных комментариев для каждой паузы в речи героев.
  • Пауза между запросами к API (сек): Время ожидания между отправкой частей видео (по умолчанию 20 секунд) для соблюдения лимитов запросов в минуту (RPM).

Вкладка «Синтез SAPI5»:

  • Голос SAPI5: Выбор системного голоса Windows.
  • Скорость речи: Настройка темпа чтения (от -10 до +10 с шагом 0.1).
  • Громкость SAPI5: Уровень громкости синтезатора (0–100%).
  • Макс. разгон речи (лимит): Ограничение автоматического ускорения реплики (по умолчанию 3.0x), гарантирующее разборчивость при вписывании комментария в короткую паузу.

5. Создание проекта и организация рабочего пространства

Как открыть видео и создать проект

  1. Нажмите Ctrl + N (или меню Проект → Создать проект из видео...).
  2. Выберите исходный видеофайл любого популярного формата (MP4, MKV, AVI, MOV, TS).
  3. Программа откроет окно подготовки: нормализует контейнер и извлечет звук фильма для мгновенного перемещения по таймлайну.
  4. Проект сохранится в каталоге Projects/.

Оптимизация рабочего пространства

Когда боковые панели не требуются для работы, их можно закрыть, тем самым значительно увеличив рабочее пространство таймлайна и плеера:

  • Закрыть / открыть панель списка комментариев: нажмите Ctrl + L или кнопку на верхней панели.
  • Закрыть / открыть панель микшера и компрессора: нажмите Ctrl + M или кнопку на верхней панели.
  • Быстрое переключение пропорций окна видео:
    • Ctrl + 1 — Компактный размер окна видео (50% ширины);
    • Ctrl + 2 — Стандартный размер окна видео (65% ширины);
    • Ctrl + 3 — Крупный размер окна видео (80% ширины).
  • Полноэкранный режим видео: клавиша F11 (возврат по Esc или F11).

6. Пользовательские пожелания по тифлокомментированию (Ctrl + U)

В диалоге «Пожелания к тифлокомментированию» (Ctrl + U) можно задать персональные творческие инструкции для модели Google Gemini:

  • Указать стилистику (например, динамичный стиль для экшена, мягкий тон для сказки, строгость для документалистики).
  • Сделать акцент на мимике, жестах персонажей или обстановке.
  • Запретить или потребовать использование специфических терминов.

Инструкции сохраняются внутри проекта и автоматически учитываются при генерации комментариев.

7. Карточки персонажей («Герои фильма», Ctrl + K)

Благодаря карточкам персонажей модель Gemini точно распознает героев в кадре и называет их по именам, вместо обезличенных описаний «высокий мужчина» или «женщина в очках».

Возможности и функции базы персонажей:

  • Создание персонажа: нажмите «Добавить персонажа» (Alt + A или Ctrl + N).
  • Захват кадра из видео: встроенный в карточки плеер позволяет легко найти кадр с героем и нажать кнопку «Захватить текущий кадр» (Ctrl + Shift + C или F8). К одной карточке можно прикрепить несколько скриншотов в разной одежде и ракурсах.
  • Экспорт и импорт наборов карточек (Alt + E / Alt + I): базу созданных героев можно экспортировать в пакетный файл (ZIP/JSON) и мгновенно импортировать в другие проекты. Это чрезвычайно удобно при работе над сериалами, многосерийными фильмами или циклами передач с одними и теми же актерами.
  • Совет тифлокомментатору: Обязательно помогайте модели и создавайте карточки главных героев самостоятельно перед запуском автоматического тифлокомментирования. Это существенно повышает точность сценария.

8. Работа с комментариями на таймлайне и в списке

Создание, редактирование и перемещение

  • Создание комментария: нажмите клавишу Insert в позиции курсора воспроизведения.
  • Редактирование текста: выделите комментарий и нажмите F2 (или дважды щелкните по строке в таблице).
  • Перемещение по порядку: клавиши Ctrl + Стрелка вверх / Ctrl + Стрелка вниз в списке комментариев.
⚠️ Удаление комментариев и звука на таймлайне:

Обратите внимание: удаление тифлокомментариев и их озвучки непосредственно на таймлайне не работает по горячим клавишам, чтобы исключить случайное удаление при навигации и перемотке фильма.

Для удаления комментария или сброса звука прямо на таймлайне предусмотрено контекстное меню по правому клику мыши:

  • Щелкните правой кнопкой мыши на блоке нужного комментария на таймлайне.
  • В открывшемся меню доступны действия:
    • «🗑️ Удалить комментарий» — полное удаление тифлокомментария из проекта;
    • «🔇 Удалить озвучку (сделать не озвученным)» — удаление сгенерированного аудиофайла (текст комментария сохраняется);
    • «✏️ Редактировать текст...» — изменение текста тифлокомментария;
    • «🔊 Озвучить Gemini TTS» / «🗣️ Озвучить SAPI5» — точечная переозвучка выбранной фразы.

Примечание: В боковой панели списка комментариев удаление также доступно по клавише Delete.

9. Комментирование фрагмента видео (Ctrl + Shift + G)

Если вам нужно прокомментировать или повторно проанализировать конкретный отрезок фильма:

  1. Поставьте метку начала фрагмента клавишей [ или I (In-point).
  2. Поставьте метку конца фрагмента клавишей ] или O (Out-point).
  3. Нажмите Ctrl + Shift + G (или меню Генерация → Прокомментировать фрагмент...).
  4. Модель обработает только выделенный интервал времени и добавит созданные комментарии в проект.
  5. Чтобы снять выделение диапазона на таймлайне, нажмите Escape.

10. Озвучивание комментариев (Gemini TTS и SAPI5)

В программе реализовано два движка синтеза речи:

  • Google Gemini TTS (Ctrl + Shift + T): синтезирует выразительную человечную дикторскую речь. Напоминаем: в Настройках обязательно должна быть выбрана модель с пометкой "TTS".
  • Windows SAPI5 (Ctrl + Shift + S): локальный системный синтез без интернета.

Движок автоматически замеряет длительность свободной паузы между диалогами фильма и, при необходимости, ускоряет речь (без изменения тона и питча), гарантируя попадание комментария в паузу.

11. Звукорежиссура, микширование и компрессор

⚠️ ВАЖНО: Режим итогового звука
Переключатель «Итоговый звук (Мастер-аудио)» в панели микшера необходимо включать только перед итоговым выводом в файл для контрольного прослушивания. В процессе монтажа и навигации держите включенным режим «Обычный звук».

Шкала децибел (dB):

  • 0 dB (ноль децибел): Нормальная громкость исходных дорожек.
  • Отрицательные значения (-3 dB, -6 dB, -12 dB): Пониженная громкость.
  • Положительные значения (+3 dB, +6 dB, +12 dB): Повышенная громкость (действует при прослушивании итогового аудио и при экспорте).
🎧 Аналогия работы компрессора: Человек с ручкой громкости

Представьте внимательного человека-звукорежиссера, который непрерывно слушает фильм и держит руку на ручке регулировки громкости:

  • Он заранее «заглядывает вперед» по таймлайну (параметр Lookahead / Упреждение) и видит, что через мгновение начнется тифлокомментарий.
  • Как только комментарий начинает звучать, человек быстро и плавно убавляет громкость фильма (срабатывание компрессора и авто-дакинг), чтобы голос диктора звучал кристально четко и разборчиво.
  • Когда тифлокомментарий прозвучал, звукорежиссер плавно возвращает ручку громкости фильма обратно (параметр Release / Восстановление). Реплики персонажей фильма тут же звучат в полную силу, на той же комфортной громкости, создавая ощущение абсолютно ровного баланса.

Секрет идеального баланса:

Нужно подобрать громкость комментариев и звука фильма таким образом, чтобы комментарии звучали немного громче фильма. Тогда, при звучании тифлокомментария компрессор убавит громкость фильма, а когда комментарий прозвучит — вернет громкость, и зритель услышит диалоги персонажей на той же громкости (общая громкость будет казаться одинаковой). Подняв уровень громкости до положительных значений, можно выровнять по громкости и сам фильм, и тифлокомментарии.

12. Все виды экспорта и импорта

12.1. Экспорт полного видео в MKV (Ctrl + E)

Создает итоговый видеофайл Matroska (.mkv) с оригинальным видеорядом, звуком фильма и встроенной сведенной аудиодорожкой тифлокомментариев.

12.2. Экспорт только аудио (Ctrl + Shift + A)

Экспортирует сведенную мастер-аудиодорожку в формате MP3 или WAV.

🎭 Экспорт только аудио тифлокомментариев для открытых показов:

Для открытых показов в кинотеатрах и залах (где звук фильма воспроизводится через динамики зала, а тифлокомментарии подаются незрячим зрителям в наушники через радиоприемники) требуется дорожка только с тифлокомментариями без звука фильма.

Как это сделать: Перед экспортом аудио в правой панели микшера включите флажок «Mute» (Выключить звук видео) на регуляторе фильма, а затем нажмите «Экспорт аудио» (Ctrl + Shift + A).

12.3. Импорт и экспорт субтитров SRT (Ctrl + I / Ctrl + Shift + E)

Так уж повелось, что многие тифлокомментаторы пишут комментарии в редакторах субтитров. Программа полностью поддерживает этот процесс:

  • Импорт из SRT (Ctrl + I): мгновенно загружает готовые тексты и тайминги субтитров в проект для последующего озвучивания.
  • Экспорт в SRT (Ctrl + Shift + E): сохраняет комментарии в стандартный файл субтитров SRT (UTF-8).

12.4. Экспорт и импорт карточек персонажей (Alt + E / Alt + I)

Позволяет переносить базу героев со скриншотами между сериями и проектами.
