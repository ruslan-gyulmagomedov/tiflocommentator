# Тифлокомментатор

Программа для создания тифлокомментариев к видео: распознаёт речь, подсказывает
подходящие фрагменты через Google Gemini, даёт вставить готовые комментарии на
звуковую дорожку и собрать проект.

Интерфейс на PySide6 и рассчитан на работу со скринридерами NVDA и JAWS.

## Требования

- Windows 10/11, 64 бита
- Python 3.11 или 3.12
- Ключ Google Gemini (и по желанию ключи YouTube API), вводятся в настройках

## Сборка

Из папки с исходниками запустить `собрать.bat`. Скрипт поставит зависимости
(`requirements.txt`, PyInstaller, Pillow), соберёт exe через `build_portable.py`
и положит результат в `Portable\`, а копию — в корень проекта.

Ручная сборка:

```
python -m pip install -r requirements.txt
python -m pip install pyinstaller pillow
python build_portable.py
```

Перед сборкой в папке должны лежать `bin\ffmpeg.exe`, `bin\ffprobe.exe`,
`voice_samples\`, `logo.jpg` и `Help\` — скрипт проверяет их наличие.
Бинарники ffmpeg в репозиторий не кладутся из-за размера, их нужно положить
рядом с исходниками.
